## 2. 对 dsh Chat 的判断

定位差异：

- **去中心化 + 端到端**：没有服务端账号/权限系统，群成员管理只能 advisory；不追 WhatsApp/Telegram 的"踢人/封禁"。
- **桌面/Web 优先的开发者工具插件**：不值得做视频通话、贴纸商店、频道生态；应把"文字/文件/群协作/通知/隐私"做到位。
- **agent 协作是差异化**：`@chat`、MCP、bridge、Agent ID 是竞品没有的，应继续强化，而不是照搬消费级 IM 的全部娱乐功能。

## 3. 差距清单（按优先级）

### P0（本轮必须）

1. **静音真正生效**：当前会话 `muted` 只是列表标记，系统通知、未聚焦 toast、提示音仍然触发；应在提醒层统一检查。
2. **Emoji 选择器**：输入区只有文本，缺表情入口；需要分类 + 最近使用 + 光标位置插入，不依赖第三方库。
3. **消息置顶**：Host 已需支持持久化；客户端补：会话顶部置顶条、置顶列表、点击跳转、hover 操作"置顶/取消"。
4. **隐私开关**：已读回执 / 正在输入 / 最后在线三项可关闭；Host 停止发送回执/typing，客户端停止显示对方 last seen。
5. **Logo 重做**：现有图标仍被判定"廉价"；本轮基于 Hermes/UI 概念重做，走品牌字标/抽象几何方向，不再做卡通动物。

### P1（下一轮）

6. ✅ 逐条消息投递状态（pending/failed/retry）+ 断线自动重试：v4.1.0 已实现（v4.0 之后）。
7. 语音消息：MediaRecorder 录音 → 加密附件 → 波形/时长气泡。
8. 链接预览：Host 抓取 Open Graph（注意 SSRF 与隐私，只对明确 http(s) 且非内网），失败静默降级。
9. 搜索过滤器：按发送人、日期、媒体类型过滤；搜索结果高亮。
10. ✅ 仅 @我 提醒（v4.2 每会话通知模式）；免打扰时段与移动端滑动操作仍待做。
11. 标记未读、收藏消息、本地导出会话 JSON。
12. 二维码邀请（把邀请码渲染成 QR，纯前端实现）。

### P2（远期/明确取舍）

13. 多设备同步、消失消息、设备验证：需要新的同步/密钥协议，不是 UI 工作。
14. 视频通话、屏幕共享、贴纸商店、频道生态：与插件定位不符，明确不做。
15. RTL、完整键盘导航、读屏实测：质量项，排期做。
